# Carbon Theme for Omarchy

A dark, sophisticated theme based on the Carbon VS Code theme, featuring deep navy blues with coral/pink accents.

## Color Palette

- **Background**: Deep navy blue (`#172030`)
- **Foreground**: Soft silver (`#c9cccd`)
- **Accent**: Coral pink (`#db6e89`)
- **Selection**: Muted blue (`#214760`)

## Installation

### Option 1: Manual Installation

Copy this folder to your Omarchy themes directory:

```bash
cp -r carbon ~/.config/omarchy/themes/
```

Then select the theme using `Super + Alt + Space` → Style → Theme → carbon

### Option 2: From GitHub (if published)

```bash
omarchy-theme-install https://github.com/YOUR_USERNAME/omarchy-carbon-theme
```

## Backgrounds

Add your preferred background images to the `backgrounds/` folder. Press `Super + Ctrl + Space` to cycle through them.
